# A2 — 词条 / 标签 / Sigil 系统竞品研究

> **目的**：为本项目（炼金/巫术主题、3 词条槽/卡、80 词条池、50–80 反应对、营地拼装、词条来自吞噬敌人）寻找可借鉴的语义模型、获取与拆装机制、synergy 设计、平衡边界。
> **方法**：以语义粒度、获取/装配、synergy、平衡四个轴对每款竞品展开。
> **范围说明**：Inscryption / MTG / Magicraft / Stacklands / Backpack Hero / Loop Hero / Vault of the Void。

---

## 0. 评估轴定义

- **语义模型**：词条的内部语法（动词+名词？触发器+效果？纯形容词？）
- **获取**：拆卡 / 合卡 / 随机 / 掉落 / 商店
- **使用**：永久附加？可拆？消耗？转移？
- **Synergy**：成对、三件套、链式、矩阵、纯叠加
- **平衡边界**：玩家著名 break-the-game combo

---

## 1. Inscryption（重点参考——最像本项目）

### 1.1 语义模型：**「触发器 + 效果」单元(Sigil)**
Inscryption 的 sigil 是**自含语义的小图标**，一张卡可挂 0–2 个原生 sigil；语法极简，几乎都是「在 X 时刻，做 Y」或「拥有 Z 属性」：

| 类别 | 示例 | 语法形式 |
|---|---|---|
| **战斗修饰**（攻击如何打） | Airborne（空袭对面玩家而非生物）/ Bifurcated Strike（双路攻击）/ Trifurcated Strike / Mighty Leap（无视空袭） / Sharp Quills（被攻击时反伤 1） | "When attacking, do X" |
| **触发型**（死亡/受伤时） | Many Lives（牺牲不死）/ Worthy Sacrifice（牺牲时给 +3 血）/ Stinky（对面 -1 攻击）/ Loose Tail（被攻击时召一只兔子顶替） | "On death/hit, do X" |
| **持续状态** | Touch of Death（任何伤害=致死）/ Made of Stone（无视致死与毒）/ Frozen Away（死后变成新生物） | passive property |
| **生成型** | Bone King（死时给 +4 骨头）/ Hoarder（入场后抽指定卡）/ Ant Spawner（入场召蚂蚁）| spawn/draw |
| **回合循环** | Sprinter（每回合横移一格）/ Leader（旁边友军 +1 攻）/ Fledgling（N 回合后变身）/ Fecundity（入场时复制自身）| per-turn / aura |
| **位置型** | Waterborne（每隔一回合潜入水中无法被打到）/ Burrower（自动钻洞挡攻击） | spatial |

**关键洞察**：Inscryption sigil 的「原子粒度=完整效果」与本项目设定 **完全一致**。每个 sigil 可独立成立、不需要外部参数。

### 1.2 获取：吞噬 + 转移（这是金矿）
- **天然**：怪物自带 1–2 个 sigil（牺牲/吞噬来源）。
- **Pelt（皮草）的 Trader**：花皮草买稀有牌（自带高价值 sigil）。
- **Bone Lord 之刃 / 营火**：付出生命/牌槽永久升级。
- **Totem 头**：地图随机奖励，把「兽族 X」+「sigil Y」组合在一起，**该 run 内所有该兽族牌自动获得该 sigil**——这是 Inscryption 最强的 emergent 设计。
- **Deathcard**：玩家自定义死亡牌，自带最多 2 个选择 sigil（Act 1 一周目结束解锁）。
- **第三只眼/牺牲秤**：某些事件可强行往牌上加 sigil。

### 1.3 使用：永久附加，**可叠加但不可拆卸**
- sigil 一旦上了卡就**不能取下**（除非该卡死亡或被牺牲）。
- 同一 sigil **不可在同一卡上叠加**（无双倍 Touch of Death）。
- 不同 sigil 可叠加到上限（卡面预留 2 槽，多余 sigil 通过缩小图标显示）。
- Squirrel/Stoat 这类 token 牌也可拥有 sigil → 玩家会把 squirrel 改造成怪物。

### 1.4 Synergy 设计：**链式触发 > 成对组合**
Inscryption 的 synergy 不是「两两查表」，而是**相同事件被多个 sigil 监听**：

- 「攻击」事件被 Bifurcated Strike → Touch of Death → Sharp Quills 同时触发，结果是「分裂成两路致死攻击 + 反伤」。
- 「死亡」事件被 Many Lives → Worthy Sacrifice → Bone King 同时触发，结果是「不死 + 给队友 +3 血 + 给玩家 +4 骨」。
- **触发栈天然涌现**——不需要列举 80×80 反应对。

### 1.5 著名 break-the-game combo
1. **Touch of Death + Sharp Quills + Many Lives**：被打反伤致死 + 自己不死 → 单卡屠灭整波。
2. **Bifurcated/Trifurcated + Touch of Death**：分裂攻击秒所有 column。
3. **Pack Rat + Hoarder + 0 攻松鼠 token**：抽 Pack Rat → Pack Rat 出场抽 Pack Rat → 死循环。
4. **Mantis God（Trifurcated 自带）+ Sharp Quills 转移**：清场永动机。
5. **Worthy Sacrifice + Ouroboros**：每次牺牲 Ouroboros 永久 +1/+1，配合 +3 血叠成天文数字。
6. **Sprinter + Touch of Death**：每回合横移 = 每回合擦死隔壁。

### 1.6 给本项目的核心启发
- **触发器+效果**的统一语法（不要混杂数值修饰和触发逻辑两套语法）。
- **同 sigil 不可同卡重复**（避免 ×4 双倍堆叠的破坏性）。
- **Totem 式族群广播**——值得做一个「该 run 所有 X 类敌人吞下来都自带 Y」的稀有事件。

## 2. MTG 关键字能力（keyword abilities）

### 2.1 语义模型：**纯标签（一词一规则）**
MTG keyword 是**对长规则文本的命名压缩**。每个 keyword 对应一段 Comprehensive Rules 中的硬规则，玩家只需记忆名称：

| 进攻类 | Flying / Trample / First Strike / Double Strike / Haste / Menace / Prowess / Shadow |
|---|---|
| **防御类** | Vigilance / Reach / Defender / Indestructible / Hexproof / Ward / Shroud / Protection |
| **结算类** | Lifelink / Deathtouch / Flash / Fear / Intimidate |
| **机制类** | Cycling / Flashback / Cascade / Storm / Convoke / Affinity / Delve（这些是 set-specific）|

**Evergreen**（每代都用的常青）目前约 20 个；非常青 keyword 在每个 set 单独引入。

### 2.2 获取：内嵌于卡，不可单独「获取」
- MTG 的 keyword 是**卡设计师在印卡时附加**的，玩家**不在游戏中获取 keyword**。
- 但是 **Auras / Equipment / Counter** 会临时**赋予** keyword（"target creature gains flying until end of turn"）。
- 这一点和我们「玩家获取词条」的模型差异最大——MTG 的玩家自由度不在词条层，在牌组构筑层。

### 2.3 使用：永久（印在卡上）/ 临时（赋予）
- 同一 keyword **不叠加**（飞行不会因为多个来源而变成"双重飞行"）。
- 但部分 keyword 自带数值（Ward 2 / Protection from Red / Annihilator 3），数值之间叠加规则 case-by-case。

### 2.4 Synergy：**矩阵化 + 数据规模**
- MTG 不靠「两两反应表」，而靠 keyword 的**正交组合**：Flying（无视陆地阻挡）× Lifelink（伤害=吸血）× Trample（溢出）= 一个无解的飞行吸血碾压生物。
- 设计模式：每个 keyword 选择一个**结算阶段**，让组合出现在结算管线的不同节点 → 自动正交。

### 2.5 著名 break-the-game
- Splinter Twin + Deceiver Exarch（无限战斗）
- Storm + Tendrils of Agony
- Cascade + 0-mana 卡（Living End / Crashing Footfalls）
- 这些都是「关键字之间的乘法」而非「关键字两两反应」。

### 2.6 启发
- **关键字命名要"读得懂"**：玩家应能从名字推测大致行为（Flying = 飞行，Lifelink = 吸血）。
- **数值化关键字**（Ward N / Annihilator N / Trample N）让一个语义槽承载多个强度档。
- **Aura/Equipment 赋予**给本项目「营地拼装」一个对照：本项目允许「拆装」是更高自由度。

## 3. Magicraft（动作 roguelike，但词条系统优秀）

### 3.1 语义模型：**主体 + 修饰词链（顺序敏感）**
Magicraft 的法杖结构是**多个槽位串联**，每个槽位放一个：
- **核心法术**（投射物 / 激光 / 召唤 / 范围）
- **修饰符**（伤害 +%、追踪、分裂、穿透、链反应、元素附魔、反弹）
- **触发器**（冷却、概率、连锁触发下一槽）

槽位**顺序决定结算**（左→右），与 Noita 同源。

### 3.2 获取：随机掉落 + 商店 + 神龛重铸
- 战利品池 + 商店购买 + 重抽（rerolling）。
- 没有「拆解敌人」的获取路径——这是本项目的差异化设计。

### 3.3 使用：可拆 / 可装 / 限槽
- 法杖槽位有限（5–8 槽），mana 消耗叠加。
- 任意拔插，营地外可重排。

### 3.4 Synergy：**修饰符乘法 + 元素反应表**
- 元素之间有反应（火+油=燃烧、雷+水=链电、冰+碎=爆发）——**是显式反应对**，约 20–30 对。
- 修饰符之间靠数值相乘（"分裂 ×2" + "穿透" + "追踪" = 自动制导霰弹）。

### 3.5 平衡难点
- 「自动施法」型 relic + 高分裂 + 链反应 = 屏幕变成像素汤，FPS 暴跌（**性能边界即平衡边界**）。
- 「无消耗法术」+ 「下一发免费」= 永动机。

### 3.6 启发
- **元素反应表是工程友好的**：每个反应是一个 (词条 A, 词条 B → 效果 C) 三元组。50–80 对中可用此结构。
- **顺序敏感**对本项目可选。3 槽位若顺序敏感会让 80×80×80=51 万种排列，**不要做**——本项目应保持**顺序无关**（集合而非序列）。

## 4. Stacklands（拼词系统的极简形式）

### 4.1 语义模型：**卡=名词，叠卡=动词**
Stacklands 没有显式词条；**两张卡叠在一起=触发隐式配方**（村民+浆果丛=采浆果，木头+稻草=小屋）。
- 每个组合是一个 **(名词集合 → 名词)** 的配方。

### 4.2 获取：抽包 + 合成
- 出生包 + 商店包 + 任务包，所有内容物随机。

### 4.3 使用：拖动叠加，**消耗式**
- 大部分组合**消耗输入卡**（村民例外）。

### 4.4 Synergy：纯配方表（约 200+ 配方）
- 没有 emergent，全是预设。

### 4.5 平衡：稳定
- 很难 break，因为消耗式 + 时间压力（月末饥饿）。

### 4.6 启发
- **「叠在一起触发反应」是强烈的物理隐喻**——本项目可考虑：在营地上把两张词条卡相邻放置预览 synergy。
- 但 Stacklands 反应数 ≈ 配方数 = 不 emergent，本项目要的是 **emergent**，不应抄此模式。

---

## 5. Backpack Hero（物品组合而非词条）

### 5.1 语义模型：**物品 + 空间属性（位置/朝向/邻接）**
- 每件物品有自身效果（剑造伤、盾减伤、戒指 buff），但**关键 modifier 是空间**：
  - 「在底排时」「左侧/右侧物品」「朝向上」「同行物品数 ×」「相邻 X 类物品时」。
- 物品本身=Inscryption 卡；空间关系=本项目的「同卡词条 synergy」对应物。

### 5.2 获取：商店 / 战利品 / 合成升级
- 拾取，而非拆敌人。

### 5.3 使用：**自由摆放**，背包格子有限
- 战斗中不可改、营地可自由排。这与本项目「营地拼装」非常吻合。

### 5.4 Synergy：**邻接矩阵 + 类别标签**
- "本卡每相邻一件武器 +2 攻"、"本行有 3 件法术时触发"。
- 不是反应对，是**位置敏感的 aura**。

### 5.5 著名 break-the-game
- 「重击+连击+暴击堆叠」：重武器 + 连击戒指 + 暴击戒指叠到溢出。
- 「能量永动」：低耗能量产出 > 高耗能量消耗的循环。

### 5.6 启发
- **空间维度**作为 synergy 的载体，本项目 3 槽/卡天然有"位置"概念——第一/二/三槽可设计**槽位差异化**（如槽 1 = 触发器，槽 2 = 效果，槽 3 = 修饰）；这能压缩反应对设计空间。

## 6. Loop Hero（卡牌放置但有强 synergy）

### 6.1 语义模型：**地形卡 + 邻接修改**
- 每张地形卡有基础效果（山+HP，森林+攻速，吸血鬼宅邸生成怪）。
- **相邻**改变效果：山堆 9 个变巨岩；墓地+战场=幽灵；吸血鬼宅邸+村庄=废墟。

### 6.2 获取：战斗后从卡组发牌
- 不是拆敌人，是构筑前定 deck。

### 6.3 使用：放在循环路径上，**永久**直到 loop 结束
- 不可移除（除少量特殊机制）。

### 6.4 Synergy：**地块 × 邻接矩阵**（约 30 对显式 + emergent）
- 经典 combo：吸血鬼宅邸 + 村庄 = 废墟 = 高级敌人 + 高战利品；草原 + 沼泽 = 草原失效。
- 既有正向也有**反向**（互相抵消）的反应——这是本项目可借鉴的"负 synergy"设计。

### 6.5 著名 break-the-game
- 全图刷山+岩浆地块的"经验农场"。
- 战场+墓地+大墓地的"幽灵经验循环"。

### 6.6 启发
- **负反应对**（A+B 互相削弱）和正反应对应当**1:3 比例混合**——纯正反应让玩家无脑堆同元素。
- 「2 张同地形相邻」和「9 张同地形堆叠成新东西」两种不同尺度的 synergy 都值得借鉴。

## 7. Vault of the Void（StS-like 但有词条/标签系统）

### 7.1 语义模型：**牌身 + Discipline 槽（最多 2–3 槽）+ 牌身 keyword（Exhaust/Purge/Ethereal/Innate）**
- Discipline 是**类似 sigil 的小修饰**，每张卡有限槽，营地间可加卸。
- Discipline 例：增伤 +X、抽 +1、护甲 +X、增加冷却、改变能量消耗、施加 status。

### 7.2 获取：**从战利品/商店买 Discipline，独立于卡**
- 这是本项目最相似的获取模型！discipline 是独立物品，可装可拆可换卡。

### 7.3 使用：**完全自由拆装**（在营地）
- 每张卡有 1–3 槽 discipline；玩家可任意调度，但战斗中固定。

### 7.4 Synergy：**卡 × discipline + discipline × discipline**
- 类型标签（Attack/Skill/Power）触发某些 discipline。
- "本牌每被打出 1 次累积 1 stack"型计数器型 discipline。

### 7.5 著名 break-the-game
- 0-cost 抽牌循环 + 减费 discipline。
- 防御卡上挂"造成攻击伤害"discipline 跳过攻击防御 buff。

### 7.6 启发
- **独立战利品+任意拆装**模型与本项目营地拼装高度吻合。
- **战斗中固定/营地自由**的边界划分是必须的——不要让玩家在战斗中改词条。

## 9. 设计建议（≤300 字）

**1. 80 词条池分类——三轴正交，避免单一分法**

不要纯按元素分（火/水/土/气）会逼玩家堆同元素；推荐**三轴**：
- **触发时机**（约 6 类）：入场 / 受击 / 攻击 / 死亡 / 回合开始 / 持续光环。
- **作用域**（约 4 类）：自身 / 单卡 / 全场 / 玩家资源。
- **元素/学派**（4–6 类）：火、寒、毒、亡灵、机械、灵能——只作 flavor，不限定 synergy。

每词条 = (时机, 作用域, 学派) 三元组。80 词条覆盖 6×4×约5=120 格的 70%。

**2. 50–80 反应对怎么挑**

- **70% 同时机反应**（如「攻击+攻击」=分裂；「死亡+死亡」=连锁），易理解。
- **20% 跨学派反应**（火+油=爆炸、寒+水=冰封、毒+腐=瘟疫），制造经典联想。
- **10% 反向/抑制反应**（寒抵消火、净化抵消毒），防同色无脑堆。
- **避免** 三件套——80 词条池下三件套组合 8 万级，玩家不可记忆。

**3. Inscryption sigil 直接借鉴 5 条**

1. **同词条同卡不可重复**（无双倍 Touch of Death）——避免线性破坏性。
2. **触发器栈而非两两查表**：同事件多词条监听，反应自然涌现。
3. **Totem 式族群广播**：稀有营地事件「该 run 所有 X 怪吞下来自带词条 Y」。
4. **吞噬即获得**：杀的敌人 = 词条池来源；强敌带强词条，弱敌带白板词条；建立强度阶梯。
5. **死亡牌自定义**：玩家用淘汰的怪物词条**捏一张永久死亡牌**作为 meta 进度，跨 run 携带 1–2 词条入场。
