# A4 — 经济与数值平衡：竞品研究

> 研究范围：Slay the Spire 1 / Monster Train 2 / Inscryption (Act 1) / Vault of the Void / Tainted Grail: Conquest
> 我方设定：卡组 15-20，词条池 ~80，每张卡 3 槽（1 槽基底），敌人掉词条（1-3/敌），单局 30-40 分钟、12-15 战 + 3 boss。
> 数据来源：作者综合公开 wiki / 社区指南 / 实机数据（注：本次撰写时外网访问受限，数值以广为流传的公开版本为准，实装需校对当前补丁）。

## 1. 竞品逐项剖析

### 1.1 Slay the Spire 1（金币 / 药水 / 残骸）

| 项目 | 数值 / 机制 |
| --- | --- |
| 货币种类 | **1.5 种**：金币（主货币）+ 药水栏位（隐性资源） |
| 单战金币 | 普通战 10–20，精英 25–35，Boss 95–105；事件常给 50–175 一次性奖励 |
| 商店金币 | 卡牌：常 45-55 / 罕 65-75 / 稀 135-165；药水 50-100;遗物 150-300; **移除卡 75 起，每次+25**（A20 长 run 可破 200） |
| 核心稀缺 | **遗物购买力**（150-300）+ 移除卡价（雪球式上涨）；金币本质是"遗物 vs 卡组减负"的二选一 |
| 稀有度分布 | 战斗掉 3 选 1：常 60% / 罕 37% / 稀 3%；精英从掉率上倾向罕+稀；商店稀有度独立采样 |
| 节奏曲线 | 第 1 幕约 250-350 金；第 2 幕约 400-500 金；第 3 幕约 500-700 金（含事件）。**总进账 ~1500-1800**，全程紧张 |
| 关键决策 | 精英后："这把金够买商店遗物吗？要不要现在去移卡？该买药水吗？"——**金币永远不够花** |
| 失败惩罚 | 全归零，下次 run 仅解锁新卡池 |

**设计要点**：单货币、稀缺压力大、移除涨价是"反 deck-build greed"的关键节流阀。

### 1.2 Monster Train (1/2)

| 项目 | 数值 / 机制 |
| --- | --- |
| 货币种类 | **3 种**：金币、Pyre 升级点、Ember（遗物货币，部分模式） |
| 单战金币 | 普通节点 25-50，精英 50-75，Boss/事件 60-120；总 8 层共 3 关 |
| 商店金币 | 卡牌 45-100、单位 60-120、升级 80-160（升级是大头）、移除 75-120 |
| 核心稀缺 | **升级机会** > 金币本身。MT 的核心 build 在"已有卡叠 buff"而非加新卡，升级位有限 |
| 稀有度分布 | 单位/法术分常/稀/罕/冠军，战斗 3 选 1 中常 ~50% / 稀 ~35% / 罕 ~15%；冠军 3 阶段升级独立 |
| 节奏曲线 | 第 1 关 build 班底，第 2 关补关键稀有，第 3 关全力升级——金币越打越多但"花钱效率"也变高 |
| 关键决策 | "升级哪张？给冠军点哪条树？这个 artifact 值不值 200 金？" |
| 失败惩罚 | 全归零；MT2 引入 Mutators / Equipment 持久解锁但 run 内重置 |

**设计要点**：**升级 > 加卡** 是最大不同，鼓励玩家 sculpt 而非 hoard。

### 1.3 Inscryption（Act 1，Leshy）

| 项目 | 数值 / 机制 |
| --- | --- |
| 货币种类 | **2 种**：松鼠（场上献祭料）+ 牙齿（地图层货币，第 3/4 节点商人） |
| 单战 | 不直接掉牙齿；牙齿主要来自天平/Trader 玩法；战斗奖励是卡牌选 1 |
| 商店 | 商人收牙齿（1-3 颗换 1 张卡 / 道具），罕物常要 4-5 颗 |
| 核心稀缺 | **卡牌槽位**（手牌+ deck 体量极小，加 1 张卡是大决策）+ 高 cost 献祭素材 |
| 稀有度 | 普卡（1 血 1 攻基底）、稀有（带词缀）、唯一（剧情）三档；普:稀 ≈ 70:30 |
| 节奏曲线 | 全程"少而精"。终盘也只 8-15 张卡，不追加量追质（鹿卡、黄金牙等 game changer） |
| 关键决策 | "这张垃圾卡进 deck 之后我献祭谁？"——**deck 大小本身是惩罚机制** |
| 失败惩罚 | 死亡 = 重启地图但保留地图道具（指南针、相机），核心 deck **重置** |

**设计要点**：**少卡 + 槽位即资源** 的极限设计；和我方"15-20 卡"高度同源。

### 1.4 Vault of the Void

| 项目 | 数值 / 机制 |
| --- | --- |
| 货币种类 | **2 种**：金币（主流通）+ Aether（专用强化） |
| 单战金币 | 普通 20-35，精英 40-60，Boss 80-120 |
| Aether | 战斗后必给 5-15，事件 / 精英给 15-30；**Aether 专门用于 Imbue（词条镶嵌）和 Upgrade** |
| 商店 | 卡 30-80、移除 50-150（涨幅低于 StS）、刻印 / 镶嵌 30-100 |
| 核心稀缺 | **Aether**（绑定强化路径）；金币用于"广度"，Aether 用于"深度" |
| 稀有度 | 常/稀/罕/Void（橙），约 50/30/15/5；Void 卡需特殊节点解锁 |
| 节奏曲线 | 三幕，每幕约 60-100 Aether 进账；Aether 后期通缩 → 必须做"留 Aether 给关键卡"决策 |
| 关键决策 | "这张刚开的稀有要不要直接焊上？还是省 Aether 给后面更强的？" |
| 失败惩罚 | 全归零；但有 meta 解锁（角色升级树） |

**设计要点**：**双货币 = 双决策维度**。Aether 让"强化"独立于"获取"，最贴近我方"词条经济" 思路。

### 1.5 Tainted Grail: Conquest

| 项目 | 数值 / 机制 |
| --- | --- |
| 货币种类 | **2 种**：金币（run 内）+ 灵魂碎片 / 材料（meta + run 内打造） |
| 单战金币 | 普通 15-30，精英 40-60，Boss 60-100 |
| 商店 | 卡 30-90，强化 50-120，移除 40-100，治疗 20-50 |
| 核心稀缺 | **强化次数**（每张卡只能强化 1-2 级）+ 关键 meta 材料（解锁职业用） |
| 稀有度 | 常/稀/罕/史诗 ≈ 50/30/15/5；职业卡池 + 通用卡池双层 |
| 节奏曲线 | 9 个区域，金币随幕递增 1.3-1.5x；总进账 ~800-1200 |
| 关键决策 | "强化这张能 carry 全程吗？" + "买卡补 build 还是治疗保命？" |
| 失败惩罚 | run 内全清；meta 进度（碎片/解锁）保留 |

**设计要点**：**强化作为受限资源** 比金币更卡瓶颈，类似 MT 的"升级位"。

## 3. 我方数值建议（针对核心 6 问）

### Q1. 词条投放速率：12-15 个够吗？

**够，但需要"流动性"补丁。**
- 15-20 卡 × 3 槽 = 45-60 词条槽，其中 1/3 基底自带（15-20）→ **可由玩家填的槽 = 30-40**。
- 12-15 个掉落只能填 30-50% 槽位 → **缺口大，玩家会感到"半成品 build"**。
- 解决：① 商店 / 事件再给 5-8 个；② 词条**可拆卸复用**（拆了不消失，进库存）；③ Boss 给"双词条"或"挑词条"奖励。
- **目标进账：单 run ~25-30 个词条流通量**（含拆装），覆盖 60-75% 槽位。

### Q2. 敌人词条配置

推荐 **加权递增分布**，避免精英/Boss 与普通拉不开差距：
- **普通敌人**：60% 给 1 词条 / 30% 给 2 / 10% 不掉（彩票感）
- **精英**：100% 给 2 词条（且至少 1 稀以上）
- **Boss**：必给 3 词条，含 1 罕 / 1 主题词条
- 单 run 期望 ≈ 12×1.5 + 3×2 + 3×3 = **33 词条**（含精英 3 场）→ 配合 Q1 的"流通"可达成 25-30 实际可装。

### Q3. 80 词条池稀有度切分

**推荐 50 / 22 / 8 = 普 / 稀 / 罕**（不是 50/25/5），原因：
- 罕 5 个太少，run 间重复严重，丧失 build 多样性。
- 罕 8 个 + run 内只能见到 2-3 个 → **保稀缺感**同时**两 run 不重复**。
- 掉率：普通敌人 75/22/3，精英 40/50/10，Boss 0/40/60。

### Q4. 失败惩罚

**全归零 + 极轻 meta** 最健康：
- run 失败 → 词条库存全清、卡组全清。
- 保留：① 该套词条 build 的"图鉴解锁"（下次 run 该词条**有几率出现**而非池子永久扩容）；② 角色经验/小解锁。
- **不要**让玩家把"完美卡"带回——会打破下次 run 的探索曲线（StS 的成功就在于此）。

### Q5. 卡牌移除 / 词条拆卸成本

| 操作 | 货币 | 起价 | 涨幅 |
| --- | --- | --- | --- |
| 移除卡牌 | 金币 | 75 | 每次 +25（StS 模型） |
| 拆卸词条（保留进库存） | **金币 50 + 1 拆卸点** | 50 | 拆卸点每幕 1 个，事件可补 |
| 镶嵌词条到空槽 | **免费**（鼓励试错） | 0 | — |
| 替换已有词条（覆盖丢弃） | 金币 30 | 30 | — |
| 重铸基底槽（解锁可换） | 金币 100 + 罕道具 | 100 | 单卡 1 次 |

**设计意图**：免费镶嵌 + 付费拆卸 = 玩家敢试，但不能无成本反悔，保 build 决策重量。

## 4. 风险与调参方向

1. **词条过载**：若实测 25-30 个仍嫌多，先砍商店供应（5→3），再砍精英 +1 词条概率。
2. **货币通胀**：若玩家后期金币花不完，提高 Boss 商店罕卡价（140→200）或加入"奢侈品"（刷新装备槽 250）。
3. **词条稀缺感**：若罕词条出现频率低于 1/run，提高 Boss 保底罕（必给 1 罕）。
4. **build 同质化**：若同一 build 反复出现，给词条做"反协同"标签（互斥组），强迫玩家换思路。
